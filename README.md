# Cutie Classes ✨

Cutie Classes is a friendly educational AI learning website designed to make learning fun and simple.

## 📚 What can Cutie Classes do?

-  Ask questions and get AI explanations
-  Learn science, mathematics, history, animals, computers and more
-  Show educational images
-  Generate simple educational diagrams
-  Ask follow-up questions
-  Friendly and simple learning experience

## 🔑 What do I need?

Cutie Classes runs directly in a web browser.

You need:

-  An internet connection
- 🔑 A Groq API key
## 💻📱 How can I use Cutie Classes?

You don't need to install Python, Node.js, or any other software.

### 💻 On a PC / Laptop

1. Open this GitHub repository.
2. Download the project:
   - Click **Code**
   - Click **Download ZIP**
3. Extract the downloaded ZIP file.
4. Open the extracted folder.
5. Double-click **index.html**.
6. Cutie Classes will open in your web browser.
7. Click **🔑 Setup AI**.
8. Enter your own Groq API key.
9. Click **Save**.
10. Start learning! 🎓✨

### 📱 On a Phone

The easiest way is to use the **live Cutie Classes website** if GitHub Pages is enabled.

1. Open the Cutie Classes website link in your phone browser.
2. Tap **🔑 Setup AI**.
3. Enter your own Groq API key.
4. Tap **Save**.
5. Start learning! 

###  No installation required

No Python or other software installation is required.

## 🔑 How to get your Groq API key

Cutie Classes uses Groq to provide its AI responses.

### Step 1
Create a Groq account or sign in to GroqCloud.

### Step 2
Open the Groq API Keys page:

https://console.groq.com/keys

### Step 3
Click **Create API Key**.

### Step 4
Give your key a name, then create it.

### Step 5
Copy the API key.

⚠️ **Important:** Your API key is private. Never post it on GitHub, Discord, YouTube, or anywhere public.

### Step 6
Open Cutie Classes and click:

**🔑 Setup AI → Paste your API key → Save**

Now you can start learning! 

##  How to use Cutie Classes

1. Open Cutie Classes.
2. Click the 🔑 **Setup AI** button.
3. Enter your Groq API key.
4. Save the key.
5. Start asking questions!

### Examples

> Explain photosynthesis

> What is a black hole?

> Teach me about the human heart.

## 🔐 API Key Privacy

Cutie Classes stores the API key in the browser's local storage and uses it to communicate directly with the Groq API.

**Never publish your personal API key inside this GitHub repository.**
